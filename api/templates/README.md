# Mẫu phiếu trả lời (PDF khổ A4, có 4 ô vuông đen định vị góc)

| Thư mục | Nội dung |
|---|---|
| thpt_2025 | Phần I (40 câu) + Phần II đúng/sai (8 câu) + Phần III trả lời ngắn (6 câu) |
| thpt_2025_tuluan | Như trên (mặt 1) + mặt 2 là giấy làm tự luận và bảng điểm |
| standard_40 / 50 / 120 | Trắc nghiệm A/B/C/D 40, 50, 120 câu |
| standard_40_tuluan | 40 câu A/B/C/D + tự luận chung trên 1 tờ A4 |
